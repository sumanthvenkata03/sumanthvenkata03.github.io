## Features

- **SPA with build-time prerendering** — every route is prerendered to static HTML, so it's SEO-friendly and works without JavaScript.
- **Accessibility** — built to Section 508 / WCAG (keyboard-operable, focus management, `prefers-reduced-motion`, axe-verified).
- **Redux Toolkit** — typed state for UI preferences and the contact form.
- **Formspree contact form** — AJAX delivery to email, with validation, honeypot, and a mailto fallback.

## Local development

```bash
npm install          # install dependencies (Node 20+)
npm run dev          # dev server with hot reload -> http://localhost:5173
npm run build:static # production build + prerender every route -> dist/
```
